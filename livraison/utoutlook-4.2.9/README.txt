UToutlook Mail 4.2.9 — arm64 click package
============================================

What's new in 4.2.9
-------------------
- The yellow "?" icon and the extra unknown-app icon are gone.
- A short "starting, please wait" message appears only if start-up takes more
  than ten seconds. The app window is also re-asked to appear when needed.
- The app window no longer disappears while the app is still running, and
  sign-in no longer breaks when too many cookies are exchanged.
- Buttons in the message list are clearer (badge, two-finger hint, full labels).

Requirements
------------
- Ubuntu Touch 24.04 (noble) on an arm64 phone.
- About 120 MB of free space for the package and its data.

Install
-------
On the phone (Ubuntu Touch, arm64), from a computer:

  adb install utoutlook.mathias_4.2.9_arm64.click

or with clickable:

  clickable install utoutlook.mathias_4.2.9_arm64.click

or copy the .click file to the phone and open it from the file manager.

If an earlier version is still installed, remove it first so the launcher
shows only one UToutlook icon. Then open the app from the launcher.
